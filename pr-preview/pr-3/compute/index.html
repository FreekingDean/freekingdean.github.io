How to read this

  • Price is a typical US street price for a new unit (used for older cards, marked), not MSRP. MSRP is in the notes. Datacenter parts are rough per-GPU figures from reseller and system quotes. Cloud-only chips have no price.
  • ~1,234 means an estimate: a derived number, a rumoured or reseller-reported figure, or a range midpoint. Hover or tap the row for the basis.
  • TFLOPS / TOPS are the vendor's peak dense matrix (tensor/matrix core) figures, no sparsity. GeForce FP16 numbers use FP16 accumulate. Apple and AMD APU figures are GPU shader FP16 where there are no matrix units.
  • $/GB = price ÷ memory size. $ per GB/s = price ÷ memory bandwidth. Lower is better for both. GB/s per W is bandwidth ÷ board/system power.
  • For local LLM inference, memory size decides what fits and bandwidth roughly sets tokens per second. Compute matters more for prompt processing, training and batch serving.

Data lives in data.json. Spot something wrong? Edit it on GitHub.
